# 剧情文本表现系统设计

## 1. 文档目的

本文档定义自制剧情中的文本表现能力，包括剧情字体主题、富文本格式、专有名词字典和鼠标悬浮解释。它是主剧情系统设计文档的专项补充，服务于运行时播放层和后续 Workshop 编辑器。

本文档只描述数据约定、职责边界和演进方向，不绑定某个具体 UI Prefab，也不要求一次性实现全部能力。

## 2. 设计目标

- 让剧情作者可以使用区别于普通 NPC 对话的字体和文本主题。
- 支持颜色、加粗、斜体、下划线等局部格式。
- 支持 Mod 维护可复用的专有名词词典。
- 在文本中自动标注词典中的专有名词，并通过悬浮框显示解释。
- 保持现有 `StoryScript`、`StoryCommand` 和 `DialogManager` 的兼容性。
- 普通 NPC 对话不受剧情文本表现系统影响。

## 3. 资源与词典归属

专有名词词典按 Mod 归属，Mod 内的多段剧情共享同一份词典；单个剧情可以通过局部配置覆盖或补充词条。

推荐的查找顺序为：

1. 当前剧情的局部词条；
2. 当前 Mod 的共享词条；
3. 内置词条（如果未来提供内置世界观词典）。

同一层级出现相同 `id` 时以后加载的定义不能静默覆盖，应该在加载或校验阶段报告冲突。词条的显示文本不作为唯一标识，使用稳定的 `id` 连接显示文本和解释内容。

## 4. 数据结构方向

### 4.1 文本主题

剧情可以引用文本主题，主题负责字体和整体表现参数：

```json
{
  "style": {
    "font": "Fonts/StoryFont",
    "fontSize": 20,
    "textColor": "#F4E8C1",
    "outlineColor": "#38251A",
    "outlineWidth": 0.04
  }
}
```

字体优先使用项目已有的 TMP Font Asset，并确认其字符集覆盖目标语言。未来允许 Mod 提供字体时，资源路径遵循现有 Mod 优先、内置资源回退的规则。

### 4.2 专有名词词条

```json
{
  "id": "alien_world",
  "term": "异世界",
  "description": "位于当前世界之外的神秘区域。",
  "color": "#63D9FF",
  "bold": true,
  "italic": false,
  "underline": true
}
```

字段职责如下：

- `id`：稳定的词条标识，用于链接和查询；
- `term`：自动匹配的文本；
- `description`：悬浮解释内容；
- `color`、`bold`、`italic`、`underline`：词条在正文中的表现；
- 后续可扩展图标、音效、跳转链接，但不应让词条直接执行游戏逻辑。

## 5. 文本处理流程

剧情文本经过以下阶段：

```text
原始文本
  -> 安全处理与格式校验
  -> 合并当前剧情、Mod、内置词典
  -> 匹配专有名词
  -> 生成 TMP 富文本与稳定 link id
  -> StoryTextView 显示
  -> 鼠标悬浮时查询词条并显示 Tooltip
```

词典匹配应采用最长匹配。例如同时存在“星际”和“星际巡查”时，优先匹配“星际巡查”。匹配不能破坏已有富文本标签，也不应重复包裹已经处理过的词条。

原始文本中的富文本标签必须经过允许列表校验。至少支持：`<b>`、`<i>`、`<u>`、`<color>`、`<size>`、`<link>`。不允许 Mod 文本通过富文本直接执行命令、访问对象或改变剧情状态。

## 6. 运行时职责

建议将能力拆分为以下职责，逐步从现有 `DialogView` 中抽离：

### 6.1 StoryTextFormatter

负责原始文本的校验、词典匹配和 TMP 富文本生成，不负责创建 UI。

### 6.2 StoryGlossary

负责加载和查询内置、Mod 级及剧情级词条，并处理词条冲突和覆盖规则。

### 6.3 StoryTextView

负责使用 TMP 显示格式化文本、设置字体主题，并监听 TMP link 事件。

### 6.4 GlossaryTooltipView

负责显示和隐藏解释矩形框，根据鼠标位置和屏幕边界选择合适的显示方向。不应把 Tooltip 的布局逻辑放入剧情流程控制器。

## 7. 兼容性与降级

- 没有文本主题时，使用当前剧情对话的默认字体和颜色。
- 没有词典或词条匹配失败时，按普通文本显示。
- 词条解释为空时仍可保留颜色和格式，但不显示悬浮框。
- 字体资源加载失败时，回退到现有剧情字体，再回退到项目默认字体。
- 旧版剧情 JSON 没有新增字段时，行为保持不变。
- 普通 NPC 对话继续使用原有文本表现，不读取剧情词典。

## 8. 实现顺序

1. 调整剧情字体、颜色和描边配置，消除当前硬编码样式。
2. 抽取 `StoryTextFormatter`，先支持安全的基础富文本。
3. 增加 Mod 级共享词典和剧情级覆盖词典。
4. 增加自动词条标注和 TMP link 事件处理。
5. 增加独立 Tooltip View。
6. 在 Workshop 剧情编辑器中增加字体主题和词典维护入口。

## 9. 暂不纳入

- 词条点击后直接跳转剧情或修改任务状态；
- 复杂的上下文语义识别；
- 在线词典和跨 Mod 依赖；
- 每句话独立创建字体材质；
- 为普通 NPC 对话强行接入剧情词典。
